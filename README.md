# Інструкція з розгортання WordPress

1. **Файли:** Завантажте всі файли на сервер (Apache/Nginx).
2. **База даних:** Створіть нову БД та імпортуйте в неї SQL-дапм `database.sql` копія бази знаходиться в гілці `database`.
3. **Конфігурація:** У файлі `wp-config.php` вкажіть актуальні дані підключення до бази:
   - `DB_NAME`
   - `DB_USER`
   - `DB_PASSWORD`
   - `DB_HOST`
4. **Права доступу:** Встановіть права запису для `wp-content/uploads`.
5. **Версія PHP:** Рекомендовано 7.4 або 8.x.
